# Junkbox Star wars

An Android application developed with Kotlin and Android Studio.

## Description

This application includes a graphical interface featuring 12 buttons; each button displays an image with a corresponding sound, inspired by Star Wars.

## Features

- Graphical user interface
- 12 interactive buttons
- 12 images inspired by Star Wars
- Sound playback for each button

## Technologies

- Kotlin
- Android Studio
- Android SDK

## Purpose

This project was created as part of my Android development learning process.
